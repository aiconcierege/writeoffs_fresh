# Betti writing system

Betti speaks as the bookkeeper. The customer supplies facts, not accounting instructions.

1. Use the transaction already on screen. Don't repeat its merchant, date and amount in prose.
2. State established understanding only when it explains why the question is narrow.
3. Ask one material factual question. Use a human response as the button label.
4. Skip explanations of internal processing, allocations, saved responses or bookkeeping consequences unless they help the customer make a decision.
5. Acknowledge the click immediately; acknowledge safe persistence only after success.
6. Distinguish an answer, a deferral, a new document, background work and actual completion.
7. Keep uncertainty honest. Copy changes never promote a hypothesis into a fact.
8. Retain useful examples, necessary sensitive-data warnings and recoverable error instructions.

## Core vocabulary

| Situation | Betti says |
| --- | --- |
| Saved answer | Got it. |
| Saved deferral | No problem. I saved that for later. |
| Receipts | Do you have receipts for these? |
| Receipt follow-up | Any more receipts for these? |
| No more receipts | If not, that’s okay. I’ll keep working with what I have. |
| Real processing | I’m updating your books. |
| Nothing else needed | You’re all set for now. |
| Receipt evidence resolved a visible question | Got it — that answered this for me. |

`copy-changes.json` records exact replacements. `copy-inventory.json` inventories literal and template copy in the guided shell, steps, ordinary and special flows, canonical question projector, Home status and shared document intake. It includes shared compatibility/error paths, not just screenshots. Data-authored prompts, merchant names and factual options remain canonical inputs; this pass does not migrate persisted prompts or rewrite old action-index entries just to refresh wording.
